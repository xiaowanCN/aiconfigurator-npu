# 4 数据库表设计

> 本系统的“数据库”以性能数据表文件形式实现，数据文件为 CSV 格式（扩展名 `.txt`）。
> 本文以 `systems/data/ascend_910b/vllm-ascend/0.18.0/gemm_perf.txt` 为参考样例。

---

## 4.1 数据库表名清单

表 4 1 数据库表名清单

| 中文表名 | 英文表名 | 表功能说明 |
|----------|----------|------------|
| GEMM 算子性能表 | gemm_perf | 存储 GEMM 算子在不同量化模式（dtype）与矩阵形状（m/n/k）下的实测延迟，用于配置搜索阶段的算子耗时插值估算 |

---

## 4.2 数据库表的详细清单

表 4 2 重要表关键字段介绍（gemm_perf）

| Field | Type | Null | Key | Default | 字段说明 |
|-------|------|------|-----|---------|----------|
| framework | VARCHAR(64) | NO | | | 推理框架名称，如 vllm-ascend |
| version | VARCHAR(32) | NO | | | 框架版本号，如 0.18.0 |
| device | VARCHAR(64) | NO | | | 芯片/设备型号，如 Ascend 910B |
| op_name | VARCHAR(64) | NO | | | 算子名称，固定为 gemm |
| kernel_source | VARCHAR(64) | NO | | | 内核实现来源，如 vllm_ascend_default |
| gemm_dtype | VARCHAR(32) | NO | PRI | | GEMM 量化/数据类型，如 float16、sq、fp8 |
| m | INT | NO | PRI | | 矩阵 M 维度（输出行数） |
| n | INT | NO | PRI | | 矩阵 N 维度（输出列数） |
| k | INT | NO | PRI | | 矩阵 K 维度（内积维） |
| latency | FLOAT | NO | | | 单次算子执行延迟，单位 ms |
